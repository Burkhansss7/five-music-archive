# FIVE. Music Archive

FIVE. is a responsive music archive website created as a Web Technologies project.

The website presents five artists from different parts of modern hip-hop:

- Yeat
- Playboi Carti
- Future
- Drake
- Ken Carson

The goal of the project is to create a clean, modern and responsive music archive using HTML, CSS, Flexbox, CSS Grid, Media Queries, Bootstrap and JavaScript.

## Main Features

### Responsive Design

The website is responsive for:

- Desktop
- Tablet
- Mobile

CSS Media Queries and Bootstrap breakpoints are used to adjust layouts and typography.

### Flexbox

Flexbox is used for:

- Archive navigation
- Artist card groups
- Team cards
- Element alignment

### CSS Grid

CSS Grid is used for:

- Visual image gallery
- Icons page layout
- Grid Areas
- Responsive multi-column layouts

### Bootstrap Grid

Bootstrap's 12-column grid is used with classes such as:

- `container`
- `container-fluid`
- `row`
- `col-12`
- `col-md-6`
- `col-lg-4`
- `col-lg-6`

### Bootstrap Components

The website uses:

- Responsive Navbar
- Navbar toggler
- Buttons
- Button groups
- Cards
- Carousel
- Forms
- Input groups
- Responsive table

### Light / Dark Mode

The website includes a light and dark theme.

JavaScript toggles the `light-theme` class and stores the selected theme using `localStorage`.

### Accessibility

The website includes:

- Semantic HTML
- `nav`, `main`, `section`, `article`, `aside`, `footer`
- Image `alt` descriptions
- Accessible labels
- `aria-label`
- `aria-expanded`
- `aria-current`
- Form labels connected with input IDs
